## Pemeriksaan worker asli di Chromium

Script sekali jalan memuat `src/controller/client.ts` melalui Vite dev server pada Chromium headless 156, memakai `Worker` modul dan scheduler `MessageChannel` sesungguhnya. Tanpa error console. Angka berikut satu sampel di Apple Silicon, bukan benchmark NFR:

- 600 ms pada 20× → simTime 11,81 detik; ACK pause 0,6 ms; waktu tidak maju selama pause.
- Tambah 4 pelanggan saat pause: `atSimSec` entry = simTime ACK.
- Fast finish preset default 12 ms; cohort metrics sama dengan engine langsung untuk input log yang sama.
- Pause hidden saat fast run overload (c=1, λ=20, H=1.800) diakui 1,6 ms di simTime 550 detik.

## Belum diverifikasi

Worker pada build produksi/host HTTPS (chunk, MIME, base path, CSP) karena belum ada UI yang mengimpornya; listener `visibilitychange` dan wiring UI (WP-06); command batch A/B dan suspend (WP-08); benchmark pause ≤100 ms/cancel ≤500 ms/fast ≤2 detik pada perangkat acuan; Firefox, Edge dan Safari; siklus 20× run/reset tanpa worker tertinggal pada browser (ARC-QA-08).
