# Verifikasi AirShift TomorrowLab — 28 Oktober 2026

Scope: spike teknis dan integrasi terbatas AirShift (PRD FR-30–32, §9; ARCHITECTURE §11; DESIGN_SYSTEM CMP-16; ROADMAP §7). **Status keputusan: teknis lulus; gate produk menunggu uji manusia.** Sampai gate produk lulus, AirShift belum boleh disebut fitur yang berhasil.

## Implementasi

- **Kontrol fitur:** flag build `VITE_AIRSHIFT`. Default aktif. Build submission no-go memakai `VITE_AIRSHIFT=0 npm run build`, yang menghapus entry point, panel, worker, Wasm dan model dari hasil build. Kamera tidak pernah otomatis menyala.
- **Teknologi:**
  - MediaPipe Gesture Recognizer (`@mediapipe/tasks-vision` 1.2.0, Apache-2.0), model `gesture_recognizer.task` float16 v1 (8,4 MB, Apache-2.0).
  - Model dan Wasm disajikan dari origin sendiri (aset Vite yang hanya dimuat setelah opt-in); lisensi dan SHA-256 tercatat di `src/airshift/NOTICE.txt`.
  - Inferensi berjalan di module worker terpisah (`src/airshift/gesture.worker.ts`), bukan di simulation worker.
- **Kamera** (`src/airshift/camera.ts`):
  - `getUserMedia` dipanggil hanya setelah klik "Aktifkan AirShift" pada panel yang menjelaskan pemrosesan lokal; hanya video 320×240, audio off.
  - Sekitar 10 FPS, paling banyak satu frame in-flight; `ImageBitmap` ditransfer lalu ditutup setelah inferensi.
  - `stop()` menghentikan semua track, loop, dan worker. Izin atau model yang selesai setelah dibatalkan langsung dihentikan.
  - Track yang terputus mematikan AirShift tanpa menyentuh run.
- **Gate pose** (`src/airshift/gate.ts`, fungsi murni):
  - confidence ≥0,85; pose stabil ≥600 ms tanpa celah; hasil basi >200 ms diabaikan;
  - satu pose = satu aksi; re-arm butuh netral atau tanpa tangan ≥300 ms, ditambah cooldown 1.500 ms;
  - dua tangan → semua pose diabaikan; label "Tangan belum terlihat" muncul setelah >500 ms.
- **Guard aksi:**
  - Telapak terbuka hanya menjeda run RUNNING biasa. Jempol ke atas hanya melanjutkan pause manual atau gesture, tidak pernah pause karena tab tersembunyi.
  - Gesture diabaikan saat dialog terbuka, batch A/B aktif, fokus di kolom isian, mode Selesaikan cepat, atau tab tersembunyi, dengan feedback alasannya.
  - Controller dan worker tetap memvalidasi semua intent.
- **UI (CMP-16):**
  - Tombol AirShift di header membuka panel berisi teks consent, dua kartu pose, catatan bahwa audio tidak diminta, lalu tombol "Aktifkan AirShift" atau "Batal".
  - Saat aktif, panel menampilkan pratinjau 160×120 (tidak disimpan), status teks (off, menunggu izin, menyiapkan, siap, tangan belum terlihat, pose belum jelas, gunakan satu tangan, turunkan tangan, error), progress "Tahan pose…", dan tombol "Matikan AirShift".
  - Saat panel ditutup dan kamera masih aktif, header menampilkan "Kamera aktif" dengan tombol Matikan. Status strip menulis "Kontrol manual" atau "Manual + AirShift".
- **Tab tersembunyi:** kamera dan inferensi dihentikan seketika dan butuh opt-in ulang; run dijeda dengan alasan hidden dan hanya bisa dilanjutkan lewat tombol.

## Bukti otomatis

| Bukti | Tes | Hasil |
|---|---|---|
| Logika gate | `src/airshift/gate.test.ts` (6) | Aksi tepat sekali setelah 600 ms; celah, skor 0,84, atau berganti pose memutus dwell; re-arm 300 ms dan cooldown 1,5 s; hasil basi dan dua tangan diabaikan; label tangan hilang >500 ms; guard status/dialog/batch/isian/hidden |
| Opt-in dan privasi | e2e Chromium kamera palsu | Tidak ada panggilan kamera sebelum klik; constraint persis video 320×240 dan `audio:false`; satu-satunya host yang dihubungi `127.0.0.1:4173` (Wasm dan model termasuk); Matikan → track `ended`, chip hilang, status "Kontrol manual" |
| Hidden | e2e | Tab tersembunyi → track `ended`, pesan opt-in ulang, run "Dijeda · tab tidak aktif", tidak ada prompt ulang |
| Izin ditolak | e2e | Pesan "Izin kamera ditolak…", tombol Coba lagi, tidak ada prompt ulang otomatis, run tetap bisa dijeda manual |
| Latensi | pengukuran sekali, Chromium headless, Apple Silicon | Model siap 1,4 s setelah izin; 53 hasil dalam 5 s (~10,6/s); latensi capture→hasil median 18 ms, p95 23 ms |

Kamera palsu Chromium tidak menampilkan tangan, sehingga **akurasi pose belum terbukti** oleh tes otomatis.

## Gate produk (PRD §9.3, ROADMAP §7) — harus dijalankan manusia sebelum 13 November 20.00 WIB

Gunakan build produksi lewat HTTPS atau `npm run preview`, dengan browser yang dicatat.

| Uji | Protokol | Target | Hasil |
